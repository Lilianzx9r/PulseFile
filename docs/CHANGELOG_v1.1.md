# PulseFile v1.1

## Interaction model

- Single click selects an item.
- Double click opens a folder or opens/views a file.
- This behavior is now applied to local, FTP and HTTP explorers.
- The standalone local-volume cards on Windows also use single-click selection and double-click opening.
- The context-menu `Ouvrir` action was removed from FTP and HTTP so opening is performed only by double click.

Selection remains available through long press/right click where applicable.
