# PulseFile v0.9

## Windows / desktop

- Added a first-class **Disque local** tab alongside FTP and HTTP.
- The local storage is exposed through the existing local file browser.
- On Windows, the system drive is used as the initial local root.
- The same local storage remains available as a transfer destination.

Desktop navigation is now:

Local ↔ FTP ↔ HTTP

The existing Android storage/recent tabs are preserved.
